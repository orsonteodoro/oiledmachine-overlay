Choose an upgrade path:

  =dev-lang/perl-5.40.5		# A full rebuild is not required

or

  =dev-lang/perl-5.42.3		# A full rebuild is not required

or

  =dev-lang/perl-5.44.0		# Upgrading to this requires `emerge -vuDN system && emerge -e system && emerge -e world`


Upgrading to 5.40.5 or 5.42.3 is recommended for recent upcoming obligations.

A full upgrade to 5.44.0 (or switching between minor versions) is
recommended when a full update is long overdue and no rush to obligations.
A full rebuild is needed because not all packages have comprehensive
dependencies or the metadata of the package manager that keeps track of
subslots not updating as expected.

A version bump to either 5.40.5, 5.42.3, or 5.44.0 fixes the following CVEs:

CVE-2026-8376 - high severity, network based zero-click vulnerability, information disclosure, data tampering, denial of service, heap overflow, out-of-bounds write
CVE-2026-57432 - high severity, information disclosure, data tampering, denial of service, integer overflow, out-of-bounds read
CVE-2026-13221 - critical severity, network based zero-click vulnerability, information disclosure, data tampering, denial of service, 16-bit integer overflow, unreliable regex that may lead to access bypass/deny

Follow one of the upgrade paths below to update Perl for mitigation against
buffer overflows, integer overflow, 16-bit field overflow, out-of-bounds
write, out-of-bounds reads.


Instructions to upgrade to 5.40.5 or 5.42.3:

1. emaint sync -A

2. Add /etc/portage/package.mask/perl:
dev-lang/perl::gentoo

3. Add/update /etc/portage/package.accept_keywords/perl with the following:
=dev-lang/perl-5.42.3::oiledmachine-overlay ~amd64 **

4. Add/update /etc/portage/package.unmask/perl with the following:
=dev-lang/perl-5.42.3::oiledmachine-overlay

5. Update to 5.42.3
emerge -aovuDN =dev-lang/perl-5.42.3::oiledmachine-overlay	# Update dependencies
emerge -a1vO =dev-lang/perl-5.42.3::oiledmachine-overlay	# Force update

If you tried to upgrade 5.44.0, but want to stay on 5.42.3, you need to undo the
accept_keyword and unmask and run perl-cleaner.  The following is not required
if you didn't attempt to upgrade to 5.44.0.

6. emerge -a app-admin/perl-cleaner

7. Use perl cleaner to rebuild Perl packages.
perl-cleaner --all

8. Rebuild to downgrade `emerge -1avuDN virtual/perl-Test-Harness`


Instructions to upgrade 5.44.0:

CVE vulnerability info can be found at
https://perldoc.perl.org/5.44.0/perldelta#Security
https://perldoc.perl.org/5.42.3/perldelta#Security
https://perldoc.perl.org/5.40.5/perldelta#Security

This is for people that need to update from dev-lang/perl-5.42.2 or earlier to
the newest dev-lang/perl-5.44.0.

1. emaint sync -A

2. Add /etc/portage/package.mask/perl:
dev-lang/perl::gentoo


3. Add/update /etc/portage/package.accept_keywords/perl with the following:
=dev-perl/Compress-Raw-Lzma-2.221.0::gentoo ~amd64 **
=dev-lang/perl-5.44.0::oiledmachine-overlay ~amd64 **
=virtual/perl-Archive-Tar-3.120.0::gentoo ~amd64 **
=virtual/perl-CPAN-Meta-Requirements-2.145.0::gentoo ~amd64 **
=virtual/perl-Encode-3.240.0::gentoo ~amd64 **
=virtual/perl-ExtUtils-ParseXS-3.630.0::gentoo ~amd64
=virtual/perl-IO-1.560.0::gentoo ~amd64 **
=virtual/perl-Math-BigInt-2.5.3::gentoo ~amd64 **
=virtual/perl-Storable-3.410.0::gentoo ~amd64 **
=virtual/perl-Test-Harness-3.520.0::gentoo ~amd64 **
=virtual/perl-Test-Simple-1.302.219::gentoo ~amd64 **
=virtual/perl-Time-HiRes-1.978.0::gentoo ~amd64 **
=virtual/perl-version-0.993.400::gentoo ~amd64 **
=virtual/perl-podlators-6.0.2-r1::gentoo ~amd64 **

4. Add/update /etc/portage/package.unmask/perl with the following:
=dev-perl/Compress-Raw-Lzma-2.221.0::gentoo
=dev-lang/perl-5.44.0::oiledmachine-overlay
=virtual/perl-Archive-Tar-3.120.0::gentoo
=virtual/perl-CPAN-Meta-Requirements-2.145.0::gentoo
=virtual/perl-Encode-3.240.0::gentoo
=virtual/perl-ExtUtils-ParseXS-3.630.0::gentoo
=virtual/perl-IO-1.560.0::gentoo
=virtual/perl-Math-BigInt-2.5.3::gentoo
=virtual/perl-Storable-3.410.0::gentoo
=virtual/perl-Test-Harness-3.520.0::gentoo
=virtual/perl-Test-Simple-1.302.219::gentoo
=virtual/perl-Time-HiRes-1.978.0::gentoo 
=virtual/perl-version-0.993.400::gentoo
=virtual/perl-podlators-6.0.2-r1::gentoo

5. Emerge as follows:
emerge -aovuDN =dev-lang/perl-5.44.0::oiledmachine-overlay # Update dependencies
emerge -a1vO =dev-lang/perl-5.44.0::oiledmachine-overlay # Force update

6. emerge -a app-admin/perl-cleaner

7. Use perl cleaner to rebuild Perl packages.
perl-cleaner --all

8. emerge -1avuDN =virtual/perl-Test-Harness-3.520.0::gentoo # Update dependencies

9. emerge -avuDN		# Upgrade toolchain

10. emerge -ave system		# Rebuild the system toolchain with updated toolchain

11. emerge -ave world		# Rebuild world with new toolchain


Why use the oiledmachine-overlay Perl over the distro's release?

The oiledmachine-overlay adds additional compiler hardening flags for
Perl itself to protect security-critical Perl based apps
(e.g. password managers).
