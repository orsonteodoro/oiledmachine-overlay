There is a defect in the vendored Brotli package that contains an RCE according
to AI.  The Node.js package has several CVEs patched.

The oiledmachine-overlay mitigated the Brolti RCE but not the other
vulnerabilities at the time of the incident since we use the live ebuild by
default, but the distro uses the tagged Brolti by default.  Both distro and
oiledmachine-overlay nodejs ebuilds default using the system brolti for the
nodejs ebuild.

The brolti ebuild was switched to live as the default on Jun 17, 2026 on
the oiledmachine-overlay.

The oiledmachine-overlay will switch to live ebuilds if the project has a
security disclosure hint indicating common vulnerability fixes that the latest
tagged releases did not address.

Alleged vulnerabilites in Brolti that would have forced brotli as a live ebuild
by default or would have deserved a fallback-commit bump:

To update, replace the installed with one or more of the following:

emerge -avuDN net-libs/nodejs:26::oiledmachine-overlay
emerge -avuDN net-libs/nodejs:24::oiledmachine-overlay
emerge -avuDN net-libs/nodejs:22::oiledmachine-overlay
emerge ">=app-arch/brotli-1.2.1::gentoo" # if using stable brotli with BROTLI_PV="1.2.1" override in /etc/portage/make.conf

The distro ebuild does not have null pointer UB protection with
-fno-delete-null-pointer patch enablement but the oiledmachine-overlay does.
It is recommended to use the oiledmachine-overlay to mitigate UB leading to ACE.
