Multiple vulnerabilies were fixed in the latest PHP update.

A sample list of vulnerabilities patched:

BOR - Buffer Over-Read
CRSH - Crash
DF - Double Free
DoS - Denial of Service
H - Hang
HC - Heap Corruption
HTTPRS - HTTP Request Smuggling
ICI - Improper Cryptographic Implementation
ID - Information Disclosure
IEH - Improper Exception Handling
IF - Improper Free
IL - Infinite Loop
IO - Integer Overflow
IV - Insufficient Validation
JITM = JIT Miscompilation
LEAK - Miscellanous Leaks
LPE - Local Privilege Escalation
MC - Memory Corruption
ML - Memory Leak
NPD - Null Pointer Dereference
OOBR - Out Of Bounds Read
RCE - Remote Code Execution
RVB - Recursive Validation Bypass
SF - SegFault
UAF - Use After Free
UB - Undefined Behavior
UBMA - Unbounded Memory Allocation
UBRECUR = Unbounded Recursion
XSS - Cross Site Scripting attack

The AI claims that multiple vulnerabilities above could be used as attack chain
primitives in this vulnerability set prior to the security update.

Remediated versions

>= 8.6.0 for the 8.6 series
>= 8.5.13 for the 8.5 series
>= 8.4.28 for the 8.4 series
>= 8.3.37 for the 8.3 series
>= 8.2.36 for the 8.2 series
