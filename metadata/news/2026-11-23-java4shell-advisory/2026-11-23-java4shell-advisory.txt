This advisory only applies to users that have a CPU with AVX512VBMI.  Everyone
else is unaffected.

On the oiledmachine-overlay, not many packages use Java and not many Java based
programs are being updated daily.  So it is recommended to uninstall it since
the packages are not up to date.

If you have this CPU flags, you have 2 choices.

1. Uninstall Java (Recommended, if not used daily or if you haven't cleaned out your world file)
2. Update to latest openjdk flavor.
