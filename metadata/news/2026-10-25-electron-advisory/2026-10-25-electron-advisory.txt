It is discovered that Electron 45 and earlier used a vendored copy of Node.js
containing a vendored copy of Brotli with RCE.  If an app automatically or
passively loads an jxl image using metadata compressed with Brotli, the app is
at risk.  It is recommened at this time to either uninstall all Electron apps or
add a global deny rule for MAC (e.g. AppArmor or SELinux) for executables in
/opt/<PKGNAME> not the /usr/bin/<program-name> shell wrapper.

`equery f <pkgname>` can help find locate the folder to temporary blacklist.

Affected packages:

All Electron apps
app-misc/llocal
media-gfx/upscayl
net-im/signal-desktop [Does not work with Electron 46 alpha]
media-gfx/blockbench
media-gfx/upscayl
media-video/lossless-cut
www-apps/LobeHub
Electron 45.0.0 - with Node 24.22.0 [old version used in oiledmachine-overlay]
Electron 44.9.1 - with Node 24.22.0 [used in upstream's signal-desktop 8.32.0 release]
Electron 44.7.2 - with Node 24.21.0 [used in the distro's signal-desktop-bin 8.31.0 ebuild]

Remediated versions:

Electron 46.0.0-alpha.1 - with Node 24.22.1
Node 22.23.4
Node 24.22.1
Node 26.12.1
